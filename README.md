# TelerikTests

## RadAutocompleteTest
Sample project to reproduce a bug on the telerik radautocomplete. Requires at least a Samsung Galaxy S10 with the native Samsung keyboard.

Related : 
- https://feedback.telerik.com/maui/1716305-autocomplete-android-suggestionview-is-fully-or-partially-empty-when-keyboard-is-open
- https://feedback.telerik.com/maui/1717303-radautocomplete-android-suggestionview-is-fully-or-partially-empty

Workaround : using SuggestionViewTemplate 

Checked with Telerik.UI.for.Maui 14.0.1 / 14.1.0 / 15.0.0 and Microsoft.Maui.Controls 10.0.70 / 10.0.110
